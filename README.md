🌱 Agri-plus Pro Calculator

Smart calculations for everyday use and agriculture.

Agri-plus Pro Calculator is a multifunctional calculator designed to make mathematical and agricultural calculations easier. It combines a standard calculator with agriculture-focused tools in one application.

The project aims to provide users with a simple, accessible, and user-friendly calculation experience.

🚀 Features

1. Standard Calculator

* Addition, subtraction, multiplication, and division.
* Percentage calculations.
* Decimal operations.
* Parentheses and sign changes.
* Clear and delete functions.

2. Agriculture Mode

A dedicated mode for agricultural calculations and related operations.

3. Additional Tools

* Converter: Conversion tools.
* History: Access previous calculations.
* Rates: Currency exchange rate information.
* Settings: Application preferences.

🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

💻 How to Run the Project

1. Clone the repository:

git clone https://github.com/eaddodankwah/agri-plus-pro-calculator.git

2. Open the project folder in Visual Studio Code.
3. Open index.html in your browser.
4. Alternatively, use the Live Server extension in VS Code.

🎯 Project Objective

The objective of Agri-plus Pro Calculator is to bring standard mathematical calculations and agricultural calculation tools together in one application.

It is designed to support students, farmers, and other users who need convenient calculation tools.
